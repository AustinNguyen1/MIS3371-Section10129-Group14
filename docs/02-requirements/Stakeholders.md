# MarketStreet — Stakeholders

The following stakeholders are involved in or affected by the simulated stock-trading transaction. This is the single stakeholder list for the project; the [project proposal](../01-project-foundation/project-proposal.md#3-primary-users--stakeholders) uses the same list.

## Stakeholder Overview

| Stakeholder | Role in the Transaction | What They Need |
|---|---|---|
| **Beginner Investor (User)** | Initiates and submits a simulated stock trade order | Simple order entry, clear trade details, confirmation, and an easy-to-understand transaction status |
| **System Administrator** | Monitors the application and manages system operations | Accurate transaction records, reliable performance, and visibility into failed or rejected trades |
| **Market Data Provider** | Supplies the stock prices used to process simulated trades | Requests that follow its usage terms and rate limits, and correct attribution of its data |
| **Compliance / Audit Reviewer** | Reviews trade history and system records | Traceable records, timestamps, transaction status, and proof that business rules were applied consistently |
| **Development Team** | Builds and maintains the interface, trade rules, and data storage | Clear, consistent requirements and business rules that can be tested |
| **Course Instructor** | Reviews the transaction design and the team's implementation | Documentation and code that match each other and can be defended |

## Main Transaction

> A beginner investor submits a simulated stock trade order, and the system validates, records, and returns the transaction status.
